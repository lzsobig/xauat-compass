# 建大竞赛罗盘 (XAUAT-COMPASS) 🧭

> **西安建筑科技大学学科竞赛分级分类检索、定制选赛规划与学分折算辅助系统**  
> 专为建大学子打造：告别繁琐 PDF 翻查，全校 247 项官方竞赛分级分类一键检索、保研加分智能折算、个性化梯队选赛规划与官方报名时间线直达。

---

## 🌟 在线体验与免安装运行

- 🌐 **在线即开即用（GitHub Pages）**：[https://lzsobig.github.io/xauat-compass/](https://lzsobig.github.io/xauat-compass/)
- 💻 **本地单文件离线运行**：无需安装任何 Node.js、Python 或数据库环境，直接双击打开项目中的 `index.html` 即可 100% 离线运行。

---

## 🎯 核心功能一览

### 1. 247 项全校学科竞赛全景检索库
- **权威收录**：完整录入西安建筑科技大学教务处发布的最新《学生学科竞赛分级分类一览表（2025版）》全量 247 项赛事。
- **多维筛选**：支持按竞赛级别（国家级 / 省部级 / 校级）、主管部门分类（A 类 / B 类 / C 类 / D 类 / 拓展类）、竞赛等级（一类竞赛 / 二类竞赛 / 三类竞赛）精准穿透检索。
- **直达服务**：每项赛事均配备**官方官方报名网站链接**与**全年大致时间线（报名、初赛、决赛周期）**。

### 2. 导师级定制选赛规划
- **四梯队科学组合**：根据学生的专业方向、所在年级与参赛诉求（保研冲优 / 综合保金 / 课外学分），自动推演并生成 4 项梯队参赛方案：
  - 🥇 **冲顶金奖梯队**：冲击保研顶格加分的顶级国赛/A类赛事；
  - 🥈 **骨干中坚梯队**：拿奖胜率高、与学院专业核心紧密咬合的代表性赛事；
  - 🥉 **稳健拿分梯队**：机制稳健、性价比高、适宜拿奖保底的竞赛；
  - 💡 **跨界拓维梯队**：适合跨学科练兵与破圈交叉的创新类赛事。
- **选赛注意事项**：结合历年参赛经验，提供赛程冲突预警、跨院组队策略与避坑指南。

### 3. 保研加分与创新创业学分折算
- **标准对齐**：内置建大教务处与土木工程学院《2025 级本科生学分认定细则》折算逻辑。
- **实时核算**：输入拟参赛获奖等级，秒算对应加分绩点与创新学分，助力保研推免决策。

### 4. 2025 官方白名单核验
- **一键验真**：快速核验某项校外宣传赛事是否在建大官方白名单目录内，明确赛事认可级别，防止“误赛”水赛。

### 5. 线报与规则纠错直通渠道
- **持续维护**：左下角内置线报反馈与规则纠错入口，支持向维护者快速提交最新赛事规程或更正信息。

## 🛠️ 技术特点

- **零依赖架构（Zero-Dependency）**：纯原生 HTML5 / CSS3 / ES6+ 开发，无打包工具链门槛。
- **学术与人本视觉（Human-Centric & De-AI）**：采用建筑深蓝（Architectural Navy）与舒适 Slate 色系，排版清晰严谨，消除浮夸套壳 AI 感。
- **100% 离线自包含**：所有 247 项竞赛数据、学分折算表、图标及交互逻辑均打包在单文件中，随时随地打开即用。
