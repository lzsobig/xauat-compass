# Cloudflare 上线记录

正式地址：`https://compass.lzso.top`。

本轮沿用现有 Worker `xauat-compass` 和自定义域名，部署新版静态资源及模型 API。生产状态使用 SQLite-backed Durable Object `CompassStore`，通过原子 SQL 预留请求额度，在多请求并发时保持单卡与全站限制。

原有 21 张卡密及有效生成记录已迁入云端，迁移采用去重插入；网站运行不依赖用户电脑。模型密钥和随机管理凭据使用 Worker Secrets，不写入 Git 或静态资源。

## 实测结果

- 主页和正式来源 PDF 返回 HTTP 200，`.env` 返回 404。
- 能力接口确认模型已配置，未登录时不提供生成权限。
- 原卡密可以在正式域名兑换，返回 Secure、HttpOnly 会话 Cookie。
- 公网实际调用 `global:deepseek-v4.1-flash`，约 20.29 秒返回三项赛事与四周计划；每周工时均为测试画像设定的 6 小时。
- 流式事件顺序为 `status → status → result`。测试结果位于 `output/playwright/public-live-verification.json`。
- 处理模型偶尔使用 Markdown JSON 代码块的情况；仍拒绝截断 JSON、额外说明文字、未知赛事 ID 和超时预算。
- 本轮核心逻辑、Node 接口与 Cloudflare 存储适配测试共 37 项通过。

## 构建与维护

项目的 `wrangler.jsonc` 固定现有 Worker 与域名，`npm run deploy` 会先执行资源构建。后续发布沿用同一 SQLite 类与迁移标签，不会清空生产卡密。

后续创建或停用线上卡密使用 `npm run trial:cloud`。原本的 `npm run trial` 仅维护本机 Node 数据库。完整命令见 README。

旧版本列表、配置及旧站首页已备份到被 Git 忽略的 `runtime/deploy/`。Cloudflare 回滚需保留新 SQLite namespace 和类，避免误删生产卡密；如恢复旧页面，应保留生产 API 与存储绑定，再发布旧静态资源。

## 边界

页面、生产会话、卡密、额度和真实模型调用已验证。学生实际使用效果、真实付费转化率、实体手机键盘与不同运营商网络性能仍需后续试用验证。
