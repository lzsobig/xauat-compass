# 账号系统验收与维护

正式地址：https://compass.lzso.top，管理入口为 /#admin。

## 已实现

用户名密码注册、登录、退出、修改密码；按账号同步任务、收藏和画像；本机访客数据需本人确认后导入。卡密首次兑换后独占绑定账号，重复兑换不重置用量。管理员可查看用户和卡密、修改角色与状态、赠送日额度、重置临时密码、生成及停用卡密。

服务端每次重新校验登录会话和管理员角色。密码使用独立盐值的 PBKDF2-SHA256 哈希及服务端 AUTH_PEPPER；Cookie 为 HttpOnly、SameSite，生产环境启用 Secure。用户停用或密码重置会注销旧会话，临时密码必须修改后才能访问私有计划。

云端同步采用版本校验。并发修改触发冲突时，本机改动保留，用户选择版本前导出被替换版本的备份。退出或切换账号后，旧请求的晚到响应不能恢复到访客或其他账号。

## 验证

逻辑和接口测试：50 项通过。新增检查涵盖注册越权、会话撤销、数据隔离、卡密独占、重放、额度、密码重置、最后管理员保护及部署级恢复。

浏览器检查覆盖两台设备同步、首次导入、冲突处理、账号切换、后台赠送、卡密下载、移动布局及退出竞态，具体结果见 output/playwright/accounts/browser-report.json。

正式站点已实测注册、普通用户管理 API 返回 403、未登录私有计划返回 401、云端保存读取、账号隔离、旧版本冲突和赠送额度。登录后真实模型生成约 13.1 秒返回三项推荐和四周任务，并正确扣减额度。验收普通账号已停用。证据见 output/playwright/accounts/public-account-report.json。

## 管理员

初始管理员用户名为 compass_admin；密码仅保存在本机 runtime/管理员账号.txt。不要公开该文件。登录后可修改密码；原始凭据文件不会自动获得用户后来设置的新密码。

维护者持有部署管理凭据时，可运行 npm run admin:setup -- --recover 显式恢复管理员密码。恢复不会创建新的特权身份，并注销旧会话。普通用户由已登录管理员在后台重置临时密码。

AUTH_PEPPER 创建后必须保持稳定，生产值保存在 Worker Secrets，本机值保存在 .env。重新部署使用同一个 SQLite namespace 和迁移标签，不删除已有账号、卡密或额度历史。

## 边界

当前使用用户名密码，不声称验证了学生身份；没有短信、邮箱验证码或自动邮件找回。管理后台不展示用户私人计划、密码哈希或已发放卡密明文。实体手机系统键盘仍未单独验收。
